# دليل الهواتف (Android APK)

1. أنشئ مستودعاً جديداً على GitHub (خاصاً إن أردت) وارفع كل محتويات هذا المجلد إليه.
2. افتح تبويب **Actions** ثم **Build APK** وانتظر حتى ينتهي (نحو 3 دقائق).
3. من أسفل صفحة التشغيل نزّل **phone-directory-apk**، وفك الضغط، وانقل `app-debug.apk` إلى الهاتف وثبّته.

نسخة الويب نفسها في `index.html` وتعمل مباشرة من أي متصفح.
